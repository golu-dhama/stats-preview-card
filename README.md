# Stats Preview Card Component

A responsive **Stats Preview Card Component** built using **HTML + CSS** as part of a **Frontend Mentor** challenge.  
This project focuses on building a clean layout using **Flexbox**, adding a **purple overlay effect** on the image, and making the design fully **mobile responsive**.
